# Lophiont

The planned **parabiotic carrier for Lophiarch**, formerly **AnglerGhost**.

## Status

Design-stage project. This repository contains initial project documentation, not a working connector or agent runtime.

## Purpose

Provide a lightweight attached carrier connecting [Lophiarch](https://github.com/amiencoy/lophiarch) to external agents and graph systems. The original AnglerGhost concept focused on a BloodHound bridge; that remains a planned integration.

## Initial roadmap

- Define carrier responsibilities and attachment boundaries.
- Specify the interface between Lophiarch and external agents.
- Design a scoped BloodHound connector and its data contract.
- Explore alignment with [Parabiont Protocol](https://github.com/amiencoy/parabiont-protocol) and [Axionorm](https://github.com/amiencoy/axionorm).
- Implement a minimal adapter with explicit authorization and lifecycle handling.

Protocol compatibility, A2A support, and BloodHound integration are planned, not implemented.
